# Mitwirken

Das hier ist ein Hobbyprojekt. Es gibt keinen Fahrplan, keine Deadlines und
keine Erwartung, dass irgendwer etwas beiträgt – aber wer mag, ist herzlich
eingeladen.

## Issues

Fehler, Ideen, Fragen: einfach ein Issue aufmachen. Eine kurze Beschreibung
reicht; bei Fehlern helfen die Schritte zum Nachstellen und was stattdessen
passiert ist.

## Pull Requests

PRs sind willkommen, egal ob Tippfehler oder Feature. Bitte vorher lokal testen:

```bash
cd scripts
python -m unittest discover -p "test_*.py" -v
```

```bash
npm install
npm test
```

Kleine, fokussierte Änderungen lassen sich leichter nachvollziehen als große
Sammelpakete.

## Keine Garantie zur Annahme

Ich pflege das Projekt in meiner Freizeit und nach meinem eigenen Geschmack.
Nicht jeder Beitrag passt dazu, und manchmal dauert eine Antwort. Ein Issue oder
PR kann also auch ohne Merge enden – das ist kein Urteil über die Arbeit, nur
eine Entscheidung über die Richtung dieses Repositories. Bei größeren Vorhaben
lohnt es sich, vorher ein Issue aufzumachen.

## Lizenz

Mit einem Beitrag stimmst du zu, dass er unter der [MIT-Lizenz](LICENSE) des
Projekts veröffentlicht wird.
